## 3. Open issues (not fixed, ranked)

1. **Marine topics are slow** (your memory TODO). One month per request, sequential: 30 years ≈ 360 calls ≈ 30 min; one buoy reporting every 10 min dominates the series (4,459 of 4,628 rows in a test). Fix: thread pool + disk cache per month + thin to one value per platform and hour + cap months; better: gridded SST/waves (Open-Meteo Marine, NOAA OISST via ERDDAP).
2. **Marine code values leak as measurements**: `WIND_DIR` 361 (variable/calm), `VISIBILITY` 94–98 (WMO code table), `TOT_CLD_AMT` 9 (obscured); QC flags ignored (an SST of 0.0 °C next to 14.9 °C). `WAVE_HGT` may be in 0.5 m steps (needs checking).
3. **NOAA station search can fire ~185 requests** (`noaa_api._find_station`: one search per code per radius when the combined search is empty). Search once per radius without `dataTypes` and match codes locally, as `station_coverage._search` does.
4. **Open-Meteo quota**: requests > 2 weeks count as several calls; a 30-year area (9 grid points) ≈ 7,000 of the 10,000 free calls/day; 429 not retried. Cache yearly blocks on disk.
5. **Dateline / poles**: search boxes are clipped at ±180° (Fiji finds nothing east of 180°) and are fixed in degrees (at 70° N a 2° box is ~76 km wide).
6. **Coverage card** is NOAA-only and truncated at 3 × 1000 results.
7. **DWD file list** is cached for the process lifetime; after DWD's yearly rename URLs 404 and return `[]` silently.
8. **Hourly duplicates**: METAR/SYNOP/SPECI of the same hour are not de-duplicated. **GHCN QC flags** are not requested (`includeAttributes`).
9. **Mixed series**: `wind_speed` mixes AWND with fastest-wind codes; `precipitation` still shows an MDPR card with 1–3 values when a gauge reported a few multiday totals.
10. **Map widget**: the place search's `showRegions(true)` did not draw the boxes until the Areas button was toggled once (seen in the browser; not root-caused, it is inside the widget bundle). Area results of TMAX/TMIN/TAVG draw three station layers on top of each other.
11. **Local server serves the whole project directory** (`SimpleHTTPRequestHandler(directory=BASE_DIR)`): `/.git/config`, `/app.py`, `/.venv/…` are downloadable when running `python3 app.py`. Harmless on localhost, risky if ever exposed; Vercel only routes `index.html`, `static/**` and `/api/*`. Serve only `index.html` and `static/`.
12. **Validation with `assert`** (`interface.py`) disappears under `python -O`; use `ValueError`.
13. **Two charts per topic**: the plot panel and the "Task Output" cards show the same series. Consider collapsing the cards to a summary.
14. **Backend still defaults to Washington DC** without a selection (`DEFAULT_COORDINATE`). The UI now requires a point/region, but the API would accept it silently.

## 5. New features on the branch

* **Famous-event gallery** (`examples.py`, `GET /api/examples`): 11 events, each verified against live data (Portland 45.6 °C 28 Jun 2021, Lytton 49.6 °C, Heathrow 40.2 °C, Paris 42.6 °C, Penrith 48.9 °C, Verkhoyansk ERA5, DFW −18.8 °C, Berlin 112.8 mm, Ahr 66.2 mm, Harvey 529 mm, DC 533 mm snow depth). One click fills the form, runs it and zooms the plot to the day.
* **Notable events** (`events.py`): per result the days furthest from the normal of their time of year (±15-day calendar window), records of the range, strongest warm/cold spells; de-clustered; plain-language descriptions. Shown as numbered markers + spell bands in the timeline, an events list (click = zoom), chips on the result cards, and a **satellite image of the day** (NASA GIBS MODIS true colour, with ◀ ▶ day stepping) on the map.
* **New tools**: Sen's slope (Theil–Sen, exact ≤ 2,500 values, sampled above) and Change point (Pettitt, seasonal cycle removed).
* **Plot panel**: plain-language summary ("rose by 1.5 °C per decade — not significant; 10 years are short…"), stripes view, `p < 0.001` instead of `p 0`, tooltips explaining each tool.
* **Coverage**: 9 new worldwide ERA5 topics (humidity, dew point, sea-level pressure, cloud cover, sunshine, solar radiation, evapotranspiration, soil moisture, soil temperature) → 58 topics.
* **Usability**: topics grouped with readable names, sources and badges (model / satellite / ships & buoys / hourly), loaded on start; defaults (last 10 full years, 1 day, temperature); Apply explains what is missing and requires a point/region; Enter in the place search picks the best match; server error messages shown; map legend (collapsible); readable map popups.
